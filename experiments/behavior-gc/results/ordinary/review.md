# review

Independent review matched complete Worker behavior and GC endpoints, actor identity, scheduler thread and timestamps in 64 native workload traces, and reconstructed all 48 batch records and eight single-compilation records. Seven private package source copies matched the checkout byte for byte. Native code inspection located the optimized poll between `_IRegexpParser.parse` and `_NFABuilder.build` and the second poll between the builder and result checking. The large optimized build interval recorded 54 selections from the recycle lists.
A separate reviewer checked the header and trace for each of the 16 target executions, target-reported padding and allocation constants, both substitutions in private generator codegen.c, the 192-byte first-field offset and allocation attribute, and all 48 merged and sanitizer traces. Each target built the runtime under its own C ABI. A separate probe using the atomic definitions used in actor.c returned the same layout constants on each target.
Independent cost review recomputed the 20 paired timing differences and median RSS samples. Native disassembly showed stock scalar arithmetic folding while generated polls inhibited that folding. This supports a measured per-insertion cost for that fixture. It does not isolate the latency of a threshold check.
